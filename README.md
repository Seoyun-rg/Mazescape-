# Mazescape-
Mazescape es un juego de supervivencia en 3D. Tras un derrumbe en una cueva mística, encarnas a un cazatesoros que debe atravesar un laberinto para escapar. Explora, junta armas y combate criaturas: caza al Minotauro para obtener la llave de la puerta final y vence al guardián de 3 cabezas para ganar tu libertad.
